# Fenix Garage — Site Institucional

Homepage responsiva da Fenix Garage, especializada em bancos automotivos, adaptação, personalização e acabamento de interiores.

## Visão

O projeto combina uma apresentação institucional clara com acesso direto ao catálogo de vendas da Fenix. A experiência foi pensada para conduzir o visitante de inspiração para consulta, catálogo ou WhatsApp.

## O que está incluído

- homepage estática responsiva;
- identidade visual Fenix Garage;
- logo transparente;
- hero com fotografia real;
- catálogo externo integrado;
- WhatsApp flutuante;
- galeria de projetos;
- vídeos e imagens reais para demonstração;
- seção de compatibilidade de bancos;
- chamadas para Instagram, localização e contato.

## Estrutura

```text
Hostinger/
├── index.html
├── assets/
│   ├── logo, fotos e imagens de catálogo
│   └── vídeos de demonstração
├── README.md
└── README-HOSTINGER.md
```

## Publicação na Hostinger

Envie o conteúdo desta pasta para `public_html`. O arquivo inicial é `index.html`; não é necessário instalar dependências, executar build ou configurar banco de dados.
